# probe-moon-earth-orbital-simulation
I created a simulation of an Earth-Moon-probe three-body system based off of Kepler and Newtons orbital mechanics equations, using SciPy's RK45 ODE solver to investigate orbital stability, energy conservation, and tolerance effects.

Assignment and report were submitted as part of PHYS20035: Computational Physics and Data Science at the University of Bristol — awarded 60%
